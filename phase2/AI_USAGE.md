# AI Usage - Phase 2

An OpenAI GPT-based coding assistant helped implement signal preparation, audio-feature extraction, PCA, clustering, validation checks, and report preparation. It also helped interpret the numerical results and arrange figures and tables in the PDF.

The results were calculated by the provided Python scripts from the pinned Speech Commands mini recordings. Checks cover raw-file identity, duplicate handling, speaker separation, feature calculations, training-only fitted statistics, saved-model replay, augmentation boundaries, numerical tables, and PDF layout.

The assistant is not an audio feature or prediction model in the analytical pipeline. A complete listening review has not been carried out. The author should understand the methods, review the results, and follow the course disclosure policy.
